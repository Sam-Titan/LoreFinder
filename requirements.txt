# Direct dependencies only — every package this app actually imports (see
# each import statement under app/) or directly requires at runtime, pinned
# to the versions this project is developed and tested against. Everything
# else (torch's own numpy/sympy, chromadb's onnxruntime, celery's kombu, ...)
# is a transitive dependency pip resolves automatically; hardcoding every one
# of those (the old pip-freeze approach) triples the install size for no
# benefit and made the Docker build dramatically slower to no purpose.
#
# CPU-only torch build: this app only ever does CPU inference (local
# sentence-transformers embeddings + cross-encoder reranking), so the
# default GPU-enabled torch wheel would otherwise drag in well over 1GB of
# unused CUDA/triton packages — confirmed directly against a real build.
--extra-index-url https://download.pytorch.org/whl/cpu
